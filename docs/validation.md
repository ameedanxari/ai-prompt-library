# Validation of the version 2 overhaul

Observed 2026-10-29. This is a bounded implementation and consumer evaluation, not a guarantee of autonomous or production-ready delivery. [Public regression briefs and procedure](../evaluation/README.md) preserve the actual minimal requests and interpretation limits.

The original 970 tracked paths are inventoried and recoverable by the baseline tag. The replacement has one canonical authority, typed causal prerequisites, per-target lifecycle, separate readiness contracts, current evidence and genuine review provenance, atomic revision history, derived views and explicit legacy inspection. Package installation and the public executable are exercised outside the repository.

Independent implementation review initially found five defects and then one residual malformed-test-result defect. All were fixed with retained negative reproductions. The first complete candidate passed 72 automated checks. Trial-driven fixes added five behavioral regressions; 77 checks, TypeScript, build and local references passed on Linux Node22, macOS Node24 and Windows Node24 at commit `bd5c807`. The first Windows package example failed; line-ending normalization was added and the next three-platform run passed. Five further independent branching-report, cause-attribution, root-alias, applicability and public-CLI regressions bring the final local total to 82. CI remains attached to the actual PR head.

The gate-guidance repair makes the executable check explicit before product mutation. Diagnostic factoring preserves distinct causes while reducing one unchanged planning run's STATUS from 651,039 to 52,545 bytes and ROADMAP from 44,304 to 10,990 bytes. These are byte measurements, not observed token or cost savings. Default headless plans can omit design review; visual targets still require it.

A configured actual host remains required. The package does not ship turnkey Codex/Claude integration, authenticated identities or an OS write sandbox. Producer adherence and original-source judgment cannot be reduced to schema checks. No hosted deployment, real customer data, composed visual-product trial, hardware power-loss or general concurrent-consumer writer guarantee was evaluated here. Synthetic data exercised real local implementation; it was not represented as production customer data.

Earlier project /24 scores are not a matched control and cannot establish whether the library or additional coordinator instructions caused them. This evaluation supplies no statistical superiority estimate, charged-token measurement or universal prompt-to-production claim. Future improvements should target observed failures, preserving first attempts and real review/integration costs, rather than add keyword gates or another catalogue.

## Original-document planning rerun — 2026-10-31

A fresh producer received 28 unchanged original/adopted-decision documents, the rebuilt package at `d0aa56e`, a 19-word planning request and generic actual host transport. Prior generated plans, audits and the rubric were withheld from that producer. Context and directory separation were not an OS sandbox. A distinct reviewer assessed frozen candidates against the original sources and the retained twelve-axis rubric: **11 → 18 → 19 → 22/24**. The first three judgments were genuine rejections; the fourth approved planning/source scope, with every critical axis complete. Setup, source-allowlist clarification, actual reviewer feedback, package changes and repairs were interventions. A malformed review envelope was rejected by the host and corrected by its actual reviewer; no approval was invented. The first-pass result remains 11/24.

The trial exposed two library defects: missing estimates could look like zero effort/capacity fit, and every release prerequisite was incorrectly required to use production composition, including disposable recovery and documentary evidence. Explicit reviewed supporting criteria now retain their own evidence, lifecycle, authority and independent-review duties while delivered criteria retain production requirements. Source-conservation guidance addresses repairs that displaced original obligations or left delivered behaviors proved only in staging. Readable views now expose canonical requirements/forecast assumptions rather than silently omitting them. These fixes bring local coverage to 93 behavioral tests, alongside type checking, build and reference checks; CI must still be checked on the exact merge head.

The accepted candidate required three review-driven repair rounds. Its scope receipt does not authenticate work instructions, file lists, estimates or capacity; the independent audit separately retained and assessed their exact snapshot bytes. Real commercial inputs, access, staffing and production authority stayed pending at their consumers. No application implementation or production release was exercised in this trial. Earlier project first/final scores were 20→23, 17→23, 21→23 and 19→20 with differing setups. This rerun does not demonstrate improved first-pass quality, out-of-box autonomy, lower token use or universal prompt-to-production readiness.
