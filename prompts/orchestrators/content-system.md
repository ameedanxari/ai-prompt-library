# Content System

Load for user-facing copy/content in the active visual or artifact slice. Write concise `content-system.md` and applicable lint configuration inside the selected run when useful; do not create a mandatory whole-product content phase.

Use real product identity and source facts. Specify voice appropriate to domain, meaningful titles/actions/validation, first-run guidance, populated/empty/error/recovery states, privacy/accessibility and applicable locale rules. Unknown commercial/legal promises, prices, guarantees and policies require owner input; never invent them to fill a screen. Seed/demo data must be explicit, isolated and privacy-safe.

Inspect content in the actual composed application or intended artifact consumer. Exercise links/actions and reachable fallback/support; text files and successful builds cannot prove that users reach useful value. Generated stock copy cannot substitute for domain fit. Include content changes in relevant scope/artifact digests and invalidate affected acceptance.

Keep work cohesive with implementation/assets/tests as needed and within the slice budget. Preserve deferred requirements in the ledger. Follow the shared review/authorization policy; content-ready is not release-ready.

Never display internal specification/invariant/delivery vocabulary as product copy. Display names come from explicit profile fields, never derived from identifiers, UUID fragments or slugs. A fresh ordinary account receives no demo content; applicable demo accounts are documented with roles/setup instructions and visibly labelled, without publishing secrets. First suggested actions advance the activation milestone (first useful value), within required consent/governance. Test real account-specific roster/workspace data and reject fixture data presented as live. Navigation must reach useful content or an honest declared deferred state; never expose an unmarked scaffold. Run applicable `validate-content-lint.sh` checks and inspect actual rendered fresh/populated/recovery states; lint alone is insufficient.
