# Design Research Modules

## Purpose

Design research modules help the engines turn vague UI requests into
specific, product-appropriate interface direction before implementation
tasks are written. They are used for greenfield product design, existing
product extensions, dashboard surfaces, and screen-level UI work.

## Modules

- `mobbin-reference-intake.md` - Researches proven product patterns from
  Mobbin-style references without copying another product's design.
- `ui-reference-source-map.md` - Defines the central source-map artifact
  used by greenfield UI planning before task generation.

## Usage

Load design research modules when a feature introduces or materially
changes screens, dashboards, app flows, component systems, or visual
states. Existing product styling remains authoritative unless the user
explicitly asks for a redesign or rebrand.
