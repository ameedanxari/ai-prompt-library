# Desktop Apps Modules

Patterns for building desktop applications (Electron, Tauri, native
macOS/Windows/Linux) with OS-level integrations and offline-first
behaviour.

## Modules

| File | Covers |
|---|---|
| `native-integrations.md` | Native OS integrations — system APIs, notifications, file associations, protocol handlers, platform-specific capabilities. |
| `offline-first.md` | Desktop apps that work seamlessly offline — local data storage, sync strategies, conflict resolution. |
