# Generated Outputs

## Purpose
This directory contains all specifications, task lists, and artifacts generated by the AI Prompt Library, serving as the central repository for project deliverables and documentation.

## Instructions

1. **Review Generated Content**: Examine all generated specifications and task lists
2. **Validate Outputs**: Check generated content for accuracy and completeness
3. **Organize Deliverables**: Ensure proper categorization of generated artifacts
4. **Track Versions**: Maintain version control for generated specifications
5. **Export Documentation**: Generate final documentation and deliverables
6. **Archive Outputs**: Store completed project outputs for future reference
7. **Share Results**: Distribute generated content to stakeholders and team members

## Examples

```markdown
# Generated Project Specification

- Technical requirements and constraints

- System architecture and component design
- Technology stack and integration patterns
```

## Variables

| Variable | Description | Type | Required | Default |
|----------|-------------|------|----------|---------|
| outputFormat | Generated content format | string | No | "markdown" |
| includeVersioning | Enable version tracking | boolean | No | true |
| exportFormats | Available export formats | array | No | ["pdf", "html", "docx"] |
| archiveOutputs | Archive completed outputs | boolean | No | true |
| validateContent | Validate generated content | boolean | No | true |
| includeMetadata | Include generation metadata | boolean | No | true |
| enableSharing | Enable output sharing features | boolean | No | false |
| compressionLevel | Output compression level | string | No | "medium" |
| retentionPeriod | Output retention period (days) | number | No | 365 |

## Expected Output

This directory will contain:
- **Project Specifications**: Complete requirements and architecture documentation
- **Implementation Tasks**: Detailed task lists and development milestones
- **Generated Prompts**: AI-generated implementation prompts and guidance
- **Documentation**: User guides, API documentation, and developer resources
- **Validation Reports**: Quality assurance and testing documentation
- **Export Packages**: Formatted deliverables ready for distribution
- **Archive Records**: Historical project outputs and version tracking
- **Metadata Files**: Generation timestamps, versions, and content tracking

## Version Control

By default, this folder is excluded from version control. If you want to track your generated specs:

1. Remove `prompts/outputs/` from `.gitignore`
2. Commit the outputs you want to preserve
3. Consider using branches for different spec versions

## Regenerating Outputs

To regenerate outputs:
1. Clear this folder (or specific subdirectories)
2. Re-run the stage pipeline from the desired starting point
3. Previous outputs will be overwritten

## Notes

- Outputs are generated based on your brief and working_copy assets
- Each stage adds to or refines the outputs
- Use dry-run mode to preview outputs before full generation
