# Generated Outputs

This folder contains all specifications, task lists, and artifacts generated by the AI Prompt Library.

## Directory Structure

```
outputs/
├── specifications/    # Generated spec documents
│   ├── requirements.md
│   ├── architecture.md
│   └── features.md
├── task-lists/       # Implementation task lists
│   ├── frontend-tasks.md
│   ├── backend-tasks.md
│   └── deployment-tasks.md
├── prompts/          # Generated implementation prompts
│   └── feature-prompts/
├── documentation/    # Project documentation
│   ├── api-docs.md
│   ├── user-guide.md
│   └── developer-guide.md
└── dry-run/          # Dry-run validation outputs
    └── summary.md
```

## Version Control

By default, this folder is excluded from version control. If you want to track your generated specs:

1. Remove `prompts/outputs/` from `.gitignore`
2. Commit the outputs you want to preserve
3. Consider using branches for different spec versions

## Regenerating Outputs

To regenerate outputs:
1. Clear this folder (or specific subdirectories)
2. Re-run the stage pipeline from the desired starting point
3. Previous outputs will be overwritten

## Notes

- Outputs are generated based on your brief and working_copy assets
- Each stage adds to or refines the outputs
- Use dry-run mode to preview outputs before full generation
